# Tool Learning Log

## Tool: **Next.js**

### 10/25

* Next.js is a framework based on React used to build websites and web applications.
  
* I learned how files and folders can be used to create routes.

* Next.js supports React components, which let developers reuse parts of a website.

* I also learned that JSX lets us write HTML-like code inside JavaScript.
```js
  export default function Home() {
  return (
    <main>
      <h1>Hello World!</h1>
      <p>Welcome to my website.</p>
    </main>
  );
}
```
* `export default` allows Next.js to use this component as the page.

### 11/8

* I learned how to use JavaScript variables inside a Next.js component.

* I experimented with const to create variables that store information.
  
```js
export default function Home() {
  const name = "Daniil";
  const subject = "SEP";

  return (
    <main>
      <h1>Welcome, {name}</h1>
      <p>You are learning {subject}.</p>
    </main>
  );
}
```
* {name} and {subject}: displays the variable values inside JSX.
* JSX: allows me to write HTML like code inside the React component.
